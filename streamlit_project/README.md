# Lebanon Tourism Explorer

This Streamlit application provides an interactive exploration of tourism data across Lebanese towns.

## Features
- Interactive Tourism Index range slider
- Linked town multiselect for comparing selected towns
- Interactive Plotly bar chart
- Interactive Plotly scatter plot comparing restaurants and Tourism Index
- Key insights and design justifications

## Dataset
The application uses tourism data for Lebanese towns, including the Tourism Index and tourism infrastructure such as restaurants, hotels, and cafes.

## Interactive Features
The Tourism Index range slider filters towns based on tourism activity. The town multiselect is linked to this filter, allowing users to drill down and compare towns within the selected Tourism Index range.
